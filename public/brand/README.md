# Emplacement du logo officiel

Déposez ici le logo officiel SOS MOBILITÉ :

- `logo-sos-mobilite.png` — version principale (fond sombre de préférence), ~ 600 px de large
- `logo-icon.png` — icône carrée de l'application (1024 × 1024)

Tant que `logo-sos-mobilite.png` est absent, l'application affiche un logotype texte temporaire.
Après ajout de `logo-icon.png`, régénérez les icônes PWA : `npm run icons`.
